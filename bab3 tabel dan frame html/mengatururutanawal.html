mengatur urutan mulai

jika biasanya kita membuat list dengan urutan angka 1,2,3,4,5 dst. tetapi kita bisa mengatur urutan mulai dengan menggunakan atribut start pada tag ol. contoh :

  1. item 5
  2. item 6
  3. item 7

selain itu kita juga bisa mengatur jenis penomoran dengan menggunakan atribut type pada tag ol. contoh :

  1. item A
  2. item B
  3. item C
